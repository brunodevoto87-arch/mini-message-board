# Mini Message Board

Un tablón de anuncios simple construido con **Express** y **EJS**.

## Features

- 📝 Ver lista de mensajes
- ➕ Crear un mensaje nuevo
- 👁️ Ver detalle de un mensaje
- 🗑️ Eliminar mensajes
- 🎨 Diseño responsive

## Stack

- Node.js
- Express
- EJS
- CSS3

## Cómo correr localmente

```bash
npm install
node --watch app.js
